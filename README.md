# wrkgn

**What are folks working on?**

Discover projects and products shared in Hacker News’s recurring “What are you working on?” discussions. Search, filter by category and audience, and explore project details with links to the original posts and builders.

**[Explore wrkgn.com](https://wrkgn.com/)**

Enjoy browsing? [Star the repo](https://github.com/brainless/wrkgn) to support the project, and share bugs or feature requests in [GitHub Issues](https://github.com/brainless/wrkgn/issues). Corrections and removal requests are welcome there too.
